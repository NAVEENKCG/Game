# GTA-Style Open World Game

A browser-based open-world game built with Three.js, featuring procedural city generation, vehicle physics, combat system, and immersive audio.

## Features

- Procedural city with buildings and roads
- Third-person player controller with mouse look
- Basic HUD with health, money, and wanted level
- Web Audio API integration for sound
- High-performance rendering with shadows

## Getting Started

1. Open the project in VS Code
2. Install the required extensions (Live Server, ESLint, Prettier, etc.)
3. Start the Live Server to run the game in your browser
4. Click on the canvas to lock the pointer and control the camera
5. Use WASD to move around the city

## Controls

- WASD: Move
- Mouse: Look around
- Click: Lock pointer for mouse look

## Development

The game is built with ES6 modules and uses CDN imports for Three.js and Cannon-es. All code is in the `src/` directory, organized by feature.

## Assets

Place textures, audio files, and 3D models in the `assets/` directory.
